Python Lesson 1 — Fast Track

Python foundations — Java developer edition

You already understand programming deeply. This lesson maps everything you know in Java to Python equivalents. We skip the beginner explanations and focus only on what's different.

Part 1 — Variables and types

No type declarations — Python infers everything

Java
int age = 17; double gpa = 9.2; String name = "Yubhi"; boolean passed = true;
Python
age = 17 gpa = 9.2 name = "Yubhi" passed = True # capital T
1
Python booleans are True and False — capital first letter. Java uses true and false — all lowercase. Mix these up and you get a NameError.
2
type(variable) tells you the type at runtime: type(age) returns <class 'int'>. Python still has types — it just doesn't require you to declare them.
💡 Python has no char type. A single character is just a String of length 1: c = 'a' is the same as c = "a". Both single and double quotes work.
Part 2 — Strings

Strings are even more powerful in Python

name = "Yubhi Kashree" # All the same methods you know print(len(name)) # 13 — len() not .length() print(name.upper()) # YUBHI KASHREE print(name.lower()) # yubhi kashree print(name.strip()) # removes whitespace print(name[0]) # Y — indexing with [] print(name[0:5]) # Yubhi — slicing print(name[-1]) # e — last character print("Yubhi" in name) # True — contains check # f-strings — Python's cleaner alternative to concatenation age = 17 print(f"My name is {name} and I am {age} years old.") # My name is Yubhi Kashree and I am 17 years old. # Multi-line string bio = """ I am Yubhi. I study AI and Data Science. """
1
len(name) — Python uses a built-in function, not a method. No parentheses issue to remember.
2
name[0:5] — slicing. Extracts characters from index 0 up to but not including 5. Same exclusive upper bound rule you already know.
3
f"...{variable}..." — f-strings are cleaner than Java's string concatenation. Put any expression inside {} and Python evaluates it.
Part 3 — Lists (Python's ArrayList)

Lists replace both arrays and ArrayList

marks = [92, 88, 95, 78, 85] # no type declaration needed # Accessing print(marks[0]) # 92 print(marks[-1]) # 85 — last element print(marks[1:3]) # [88, 95] — slicing # Modifying marks.append(90) # add to end — like ArrayList.add() marks.insert(0, 100) # insert at index — like ArrayList.add(0, val) marks.remove(78) # remove by value marks.pop() # remove last element marks.pop(0) # remove at index # Info print(len(marks)) # size — like ArrayList.size() print(90 in marks) # True — contains check print(marks.index(88)) # find position — like indexOf() # Sorting marks.sort() # sort ascending — modifies original marks.sort(reverse=True) # sort descending sorted_marks = sorted(marks) # returns new sorted list # Useful operations print(sum(marks)) # sum of all elements print(max(marks)) # maximum print(min(marks)) # minimum print(sum(marks)/len(marks)) # average
1
Python lists are dynamic — no fixed size, no type restriction. One list can hold integers, strings, and objects together. Much more flexible than Java arrays.
2
sum(), max(), min() are built-in functions — no need to import Collections like Java. Python includes these for free.
Part 4 — Functions

def replaces public static returnType

Java method
public static double getAverage(int a, int b){ return (a + b) / 2.0; }
Python function
def get_average(a, b): return (a + b) / 2.0
# Python functions — key differences from Java # Default parameters def greet(name, greeting="Hello"): print(f"{greeting}, {name}!") greet("Yubhi") # Hello, Yubhi! greet("Arun", "Hi") # Hi, Arun! # Multiple return values — impossible in Java without OOP def get_stats(marks): return min(marks), max(marks), sum(marks)/len(marks) low, high, avg = get_stats([85, 92, 78, 90]) print(f"Min:{low} Max:{high} Avg:{avg}")
1
def replaces public static returnType. No return type declaration — Python figures it out. No static needed — Python functions live at module level.
2
Python naming convention: snake_case for functions and variables — get_average not getAverage. Classes still use PascalCase. This is the opposite of Java's camelCase for functions.
3
Multiple return values — Python can return a tuple of values in one return statement. Java cannot do this without wrapping in an object.
Part 5 — OOP in Python

Classes work the same — syntax is different

class Student: def __init__(self, name, roll, marks): # constructor self.name = name # self = this in Java self.roll = roll self.marks = marks def get_average(self): return sum(self.marks) / len(self.marks) def get_grade(self): avg = self.get_average() if avg >= 90: return "A" elif avg >= 75: return "B" elif avg >= 60: return "C" else: return "F" def print_report(self): print(f"Name : {self.name}") print(f"Roll : {self.roll}") print(f"Avg : {self.get_average():.2f}%") print(f"Grade : {self.get_grade()}") # Creating objects — no 'new' keyword in Python s1 = Student("Yubhi", 101, [92, 88, 95]) s2 = Student("Arun", 102, [75, 80, 70]) s1.print_report() s2.print_report()
1
__init__ is Python's constructor — double underscores on both sides. Called automatically when you create an object.
2
self is Python's this. Every instance method must take self as its first parameter — Python passes the object reference automatically when you call the method.
3
No new keyword — Student("Yubhi", 101, [92, 88, 95]) creates an object directly. No public, private, static needed for basic usage.
💡 Notice: self.marks is a list — Python lets you pass a list directly as a constructor argument. No separate array type needed. This is Python's flexibility at work.
